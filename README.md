# Página de Seleção de Recursos

Projeto desenvolvido como parte dos estudos de desenvolvimento web, com foco na construção de uma interface para seleção de recursos utilizando HTML e CSS.

## Sobre o projeto

A aplicação apresenta uma página de seleção de recursos, permitindo ao usuário visualizar e interagir com os elementos disponíveis na interface.

## Tecnologias utilizadas

- HTML5
- CSS3

## Conceitos praticados

- Estruturação semântica com HTML
- Estilização com CSS
- Organização de elementos na página
- Construção de interfaces web
